# Infinity ERP Next

A new-generation, multi-company ERP platform for Infinity Investment Group.

## Project principles

- Build independently from the existing production ERP.
- Preserve existing production operations during development.
- Enforce company-level data isolation.
- Use membership-based roles and permissions.
- Do not introduce SUPERADMIN or unrestricted system-wide administration.
- Build auditable financial and operational workflows.
- Use evidence-based AI with human approval.
- Preserve business records and approval history during migration.
